## Постановка задачи

**Вариант** — дипломный проект «Система управления и бронирования ресурсов Roomy».

Организации ведут сведения о помещениях, оборудовании, правилах доступа и занятости в разных источниках. Из-за этого пользователю сложно подобрать доступный комплект на один интервал, а администратору — поддерживать план, каталог и расписание в согласованном состоянии.

Требуется спроектировать веб-платформу для управления пространственными и материальными ресурсами нескольких независимых проектов. Участники должны находить ресурсы и бронировать их по одному или комплектом. Администраторы настраивают роли и правила, согласующие рассматривают заявки, ответственные ведут сведения об оборудовании. При включённом гостевом режиме внешний клиент может забронировать опубликованный ресурс и получить ссылку на заявку по электронной почте.

Результат проектирования должен предусматривать интерактивный SVG-план этажей, изоляцию проектных данных, предотвращение пересекающихся бронирований и журнал изменений.
